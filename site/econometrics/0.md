# 计量经济学 考前总结速览


## 一、导论

- 相关是"有关系"，因果是"改变 $X$ 会导致 $Y$ 变化"。
- **因果识别挑战**：选择偏差，处理组与对照组在干预前就存在系统性差异。
- **解决思路**：随机化实验（理想）；自然实验/准实验；计量方法。

> 计量经济学的研究步骤：理论模型；数据收集；参数估计；假设检验；模型诊断；经济解释


## 二、概率论与数理统计知识回顾

### 1. 数据结构与抽样

- **数据结构**：横截面、时间序列、面板数据。
- **随机抽样**：样本独立同分布（i.i.d.）。非随机抽样会带来**选择偏差**，使样本不具有总体代表性。

### 2. 描述性统计

- **集中位置**：均值、中位数、众数
- **分散程度**：方差、标准差、极差
- **分布状况**：偏度（对称性）、峰度（尾重）
- **线性相关**：协方差、相关系数（Pearson）

### 3. 常用分布

| 分布                           | 用途                               | 关键特征                     |
| :----------------------------- | :--------------------------------- | :--------------------------- |
| **正态分布 $N(\mu,\sigma^2)$** | 误差项分布假设                     | 对称、均值为中位数           |
| **$t$ 分布**                   | 单个系数显著性检验（$t$ 检验）     | 自由度 $n-k-1$，尾部比正态厚 |
| **$F$ 分布**                   | 多个系数联合显著性检验（$F$ 检验） | 两个自由度（分子、分母）     |
| **卡方分布 $\chi^2$**          | 异方差检验（BP/White）、LM检验     | 自由度为约束个数             |

### 4. 区间估计与假设检验

- **置信区间**：$\hat{\beta} \pm t_{\alpha/2} \cdot se(\hat{\beta})$，表示以 $1-\alpha$ 的概率包含真实参数。
- **假设检验5步走**：
  1. 设定 $H_0$ 和 $H_1$。
  2. 构造检验统计量（$t$ / $F$ / LM）。
  3. 计算统计量的值及 $p$ 值。
  4. 比较 $p$ 值与显著性水平 $\alpha$（通常 0.05/0.01）。
  5. 若 $p < \alpha$，拒绝 $H_0$，认为统计显著；否则不拒绝。

> **$p$ 值的含义**：在 $H_0$ 成立的条件下，观察到当前样本结果或更极端结果的概率。$p$ 值越小，证据越强。


## 三、经典单方程模型基础

### 1. 回归的本质

- 回归是估计 **条件期望函数** $E(Y|X)$。
- 总体回归模型：$Y = \beta_0 + \beta_1 X_1 + \cdots + \beta_k X_k + u$。
- 样本回归模型：$Y = \hat{\beta}_0 + \hat{\beta}_1 X_1 + \cdots + \hat{\beta}_k X_k + \hat{u}$。

### 2. OLS 原理与推导

OLS 选择 $\hat{\beta}$ 使 **残差平方和最小**：
$$
\min \sum \hat{u}_i^2 = \sum (Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_{1i} - \cdots - \hat{\beta}_k X_{ki})^2
$$

**正规方程的三种等价形式**：

- **形式1（残差与 $X$ 正交）**：
$$
\sum \hat{u}_i = 0, \quad \sum X_{ji}\hat{u}_i = 0 \quad (j=1,\ldots,k)
$$

- **形式2（矩阵）**：$\mathbf{X}'\hat{\mathbf{u}} = 0$。
- **形式3（估计量）**：$\hat{\boldsymbol{\beta}} = (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{Y}$。

### 3. 结构参数的经济含义

- **斜率 $\beta_j$**：在其他变量不变的条件下，$X_j$ 增加1个单位，$Y$ 的条件均值平均变化 $\beta_j$ 个单位（**偏效应/边际效应**）。
- **截距 $\beta_0$**：当所有 $X=0$ 时 $Y$ 的期望值。若 $X=0$ 无经济含义，截距可不解释。

### 4. 多元回归 vs 一元回归

- **一元回归**：$\beta_1 = \frac{Cov(X,Y)}{Var(X)}$，可能受遗漏变量影响。
- **多元回归**：在**控制其他变量**后，考察 $X_j$ 对 $Y$ 的**偏效应**，更接近因果。

> 多元回归的"控制"本质：$\beta_j$ 的 OLS 估计量来自"将 $X_j$ 对其他 $X$ 回归后的残差"对 $Y$ 的回归。

### 5. OLS 估计量的优良性质

**小样本性质**（需严格外生性 $E(u|X)=0$、同方差、无自相关）：

- **无偏性**：$E(\hat{\boldsymbol{\beta}}|X) = \boldsymbol{\beta}$。
- **有效性（BLUE）**：在所有线性无偏估计量中，OLS 方差最小（高斯-马尔可夫定理）。

**大样本性质**（只需同期外生 $E(X_i u_i)=0$）：

- **一致性**：$\text{plim}(\hat{\boldsymbol{\beta}}) = \boldsymbol{\beta}$。
- **渐近正态性**：即使 $u$ 不服从正态分布，$\hat{\beta}$ 仍渐近正态，可进行大样本推断。

> **大样本的优势**：放松了对严格外生性和正态性的要求；提高了估计精度（方差随 $n$ 增大而减小）。

### 6. 条件方差

$k=K-1$ 为解释变量斜率数目：

- 斜率：
$$
Var(\hat{\beta}_j) = \frac{\sigma^2}{\sum (X_{ij} - \bar{X}_j)^2 (1 - R_j^2)} = \sigma^2(\mathbf{X}'\mathbf{X})^{-1}
$$
其中 $R_j^2$ 为 $X_j$ 对其他解释变量回归的拟合优度。
- $\hat{\sigma}^2 = \frac{\sum \hat{u}_i^2}{n-k-1}$（残差方差的无偏估计）
- **标准误**：$se(\hat{\beta}_j) = \sqrt{Var(\hat{\beta}_j)}$

### 7. 模型整体评价

- $R^2 = SSR/SST = 1 - SSE/SST$：衡量模型解释了多少 $Y$ 的变异。
- 调整 $R^2$：对增加变量施加惩罚，用于比较不同变量个数的模型。
- **$F$ 检验**（模型整体显著性）：$H_0$: 所有斜率系数均为0。
$$
F = \frac{SSR/k}{SSE/(n-k-1)} \sim F(k, n-k-1)
$$

### 8. 虚拟变量

- **含义**：取值 0/1 的变量，用于量化性别、地区、政策等**定性因素**。
- **引入方式**：
  - **加法**：改变截距（$Y = \beta_0 + \beta_1X + \beta_2D + u$）
  - **乘法**：改变斜率（$Y = \beta_0 + \beta_1X + \beta_2D + \beta_3(D\cdot X) + u$）
- **设置原则**：$m$ 个分类 $\Rightarrow$ 引入 **$m-1$** 个虚拟变量（避免"虚拟变量陷阱"——完全多重共线性）。
- **双重差分（DID）**：
$$
Y = \beta_0 + \beta_1 D + \beta_2 T + \beta_3 (D \times T) + u
$$
$\beta_3$ = 政策效应（处理组前后变化 − 对照组前后变化），核心识别假定为**平行趋势**。


## 四、经典单方程模型进阶

### 1. 模型设定常见偏误

- **遗漏变量（OVB）**：漏掉与 $X$ 和 $Y$ 都相关的变量 $\to$ OLS 有偏且不一致。
  - 偏误方向：$\text{Bias} = \beta_{omitted} \times \delta$（$\delta$ 为遗漏变量与 $X$ 的关系方向）。
- **无关变量**：加入不相关变量 $\to$ OLS 仍无偏，但**方差增大**。
- **函数形式错误**：如线性拟合非线性关系 $\to$ 可通过 **RESET检验** 诊断。

### 2. 内生性（重中之重！）

**定义**：$Cov(X, u) \neq 0$，即解释变量与扰动项相关。

**三大来源**：

1. **遗漏变量**
2. **反向因果**
3. **测量误差**

**后果**：OLS 有偏且**不一致**。

**工具变量法（IV）**：

- 工具变量 $Z$ 的两个条件：
  1. **相关性**：$Cov(Z, X) \neq 0$
  2. **外生性**：$Cov(Z, u) = 0$
- **IV 估计量**：$\hat{\beta}_{IV} = \frac{Cov(Z,Y)}{Cov(Z,X)}$（一元）
- **2SLS（两阶段最小二乘）**：
  - 第一阶段：$X$ 对 $Z$ 回归 $\Rightarrow$ 得拟合值 $\hat{X}$
  - 第二阶段：$Y$ 对 $\hat{X}$ 回归
- **核心逻辑**：$\hat{X}$ 只包含 $X$ 中与 $u$ 无关的部分，从而获得一致估计。

**相关检验**：

| 检验                            | 目的                         | 关键阈值/判断                                    |
| :------------------------------ | :--------------------------- | :----------------------------------------------- |
| **弱工具变量**                  | 检验 $Z$ 与 $X$ 是否足够相关 | 第一阶段 $F > 10$（经验法则）                    |
| **过度识别（Sargan/Hansen J）** | 检验多余工具变量的外生性     | 不拒绝 $H_0$ 说明工具变量外生                    |
| **DWH 内生性检验**              | 判断是否需要使用 IV          | 若拒绝 $H_0$ $\to$ 使用 IV；否则用 OLS（更有效） |

**核心权衡**：IV 一致但方差大（不精确）；OLS 若外生则无偏且更有效。若 DWH 不显著，**优先用 OLS**。

### 3. 多重共线性

- **含义**：解释变量之间存在线性相关。
- **完全多重共线性**：$\mathbf{X}'\mathbf{X}$ 不可逆，无法估计。
- **高度多重共线性**：不破坏无偏性和一致性，但**方差膨胀**（标准误变大、$t$ 值变小），检验功效下降。
- **处理**：剔除高度相关变量、增加样本、变量变换（主成分等）。

### 4. 异方差性

- **含义**：$Var(u_i|X) = \sigma_i^2$ 随 $i$ 变化。
- **后果**：OLS 仍无偏一致，但 **不是 BLUE**，标准误有偏 $\Rightarrow$ $t$、$F$ 检验失效。
- **检验**：BP检验（$LM = nR^2 \sim \chi^2(k)$）、White检验（含二次项/交叉项）、GQ检验。
- **修正**：异方差稳健标准误（White标准误）、加权最小二乘法（WLS）。

### 5. 序列相关（自相关）

- **含义**：$Cov(u_i, u_j) \neq 0$，常见于时间序列。一阶自相关：$u_t = \rho u_{t-1} + \varepsilon_t$。
- **后果**：OLS 仍无偏一致，但不是 BLUE，标准误通常被**低估**（$t$ 值虚高，过度拒绝 $H_0$）。
- **检验**：DW检验（$d \approx 2(1-\hat{\rho})$）、BG检验（$LM \sim \chi^2(p)$）。
- **修正**：广义最小二乘法（GLS / 广义差分）、Newey-West 标准误。


## 五、经典单方程模型的适用性及延伸

### 1. 经典模型最佳适用条件

- 被解释变量为**连续变量**
- 数据来自**随机抽样**（横截面）
- 解释变量外生
- 扰动项同方差、无自相关

> 若数据为面板或时间序列，需相应调整。

### 2. 面板数据

**优点**：

- 信息更丰富（个体+时间）
- 控制不随时间变化的遗漏变量
- 更贴近"个体自身前后变化"的因果逻辑

**三类模型比较**：

| 模型                   | 适用条件            | 估计方法        | 核心思想                     |
| :--------------------- | :------------------ | :-------------- | :--------------------------- |
| **混合回归（Pooled）** | 忽略个体异质性      | OLS             | 所有个体方程完全相同         |
| **随机效应（RE）**     | $u_i$ 与 $X$ 不相关 | FGLS            | 将个体效应视为随机变量       |
| **固定效应（FE）**     | $u_i$ 与 $X$ 相关   | 组内去心 / LSDV | 消除个体效应，仅利用组内变异 |

**FE的识别策略（组内去心）**：

- 对每个个体求均值：$\bar{Y}_i = u_i + \bar{X}_i'\beta + \bar{\varepsilon}_i$
- 原方程减去均值：$Y_{it} - \bar{Y}_i = (X_{it} - \bar{X}_i)'\beta + (\varepsilon_{it} - \bar{\varepsilon}_i)$
- $u_i$ 被消除，无论其是否与 $X$ 相关！

**选择 FE 还是 RE**：豪斯曼检验。$H_0$: $u_i$ 与 $X$ 不相关。拒绝 $\to$ 用FE；不拒绝 $\to$ RE 更有效。

### 3. 时间序列数据特点

- **无法重复抽样**：只有"一次实现"，需依赖平稳性。
- **平稳性**：均值、方差、协方差不随时间变化。非平稳会导致**伪回归**。
- **非平稳来源**：结构变动、确定性趋势、随机性趋势（单位根）。


## 六、大考前最后叮嘱

1. **分清小样本 vs 大样本**：小样本看**无偏性**（需严格外生）；大样本看**一致性**（只需同期外生）。
2. **内生性是重中之重**：牢记三大来源、IV的两个条件、2SLS的两步流程、三大检验（弱工具/$F>10$、过度识别/不拒绝 $H_0$、DWH/拒绝 $\to$ 用IV）。
3. **面板 FE vs RE**：FE更稳健（允许个体效应与 $X$ 相关），RE更有效。豪斯曼检验做裁判。
4. **虚拟变量陷阱**：$m$ 类 $\to$ $m-1$ 个虚拟变量，否则完全共线性。
5. **DID交互项**：$\beta_3$ 是双重差分估计量 = 处理效应。
6. **异方差 + 自相关**：OLS仍无偏一致，但标准误错 $\to$ 用稳健标准误（White / Newey-West）。


> 计量经济学的核心任务是在观测数据中**分离因果关系**。OLS 是最基础的武器，但当它失效时（内生性、异方差、自相关），我们有 IV、FE、GLS、稳健标准误等整套工具箱。考试中遇到任何问题，回到**三个基本假定**——外生性、同方差、无自相关——判断哪个被违背，然后对症下药。祝考试顺利！🍀
