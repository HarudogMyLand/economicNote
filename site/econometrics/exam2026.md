## 一、概念辨析与填空

### 1. 在线性回归模型中，正确的设定形式是 $Y=\beta X + \mu$ 还是 $E(Y)=\beta X$？

这两者的区别在于是否包含随机扰动项。前者是**总体回归模型**，其中因变量 $Y$ 由系统性部分 $\beta X$ 和随机误差项 $\mu$ 两部分组成。而 $E(Y)=\beta X$ 是**总体回归函数**，表示给定 $X$ 时 $Y$ 的条件期望是 $X$ 的线性函数。

### 5. 如图是一个线性回归模型的ANOVA方差分析图，根据图表与所学知识回答问题：

填写或解读其中的各项，ANOVA表的标准格式：

| 来源（Source） | 自由度（d.f.） | 平方和（SS） | 均方 | F统计量 |
| :------------- | :------------- | :----------- | :--- | :------ |
| 回归 | $k$ | SSR | MSR = SSR$/k$ | MSR/MSE |
| 残差 | $n-k-1$ | SSE | MSE = SSE$/ (n-k-1)$ | — |
| 总和 | $n-1$ | SST | — | — |

**解答思路**：

1. **SST = SSR + SSE**，总平方和分解为回归平方和与残差平方和。

2. **$R^2 = SSR/SST$**，衡量模型的拟合优度。

3. **$F = (SSR/k) / (SSE/(n-k-1))$**，检验所有斜率系数是否同时为零（即模型整体显著性）。

4. 若 $F$ 统计量对应的 $p$ 值小于显著性水平（如 $0.05$），则拒绝原假设，认为模型整体显著。

## 二、简答题

### 第1题：什么是随机样本？如果样本不是随机抽取的，会有什么后果？

**随机样本**是指从总体中独立同分布抽取的样本，每个个体被选中的概率已知且不为零，样本能够代表总体分布。

**非随机样本的后果**：

1. **样本选择偏误**：样本概率与总体概率不一致，导致估计量不一致。

2. **遗漏变量偏误**：非随机抽样本质上是一种设定偏误，等价于遗漏了决定样本选择机制的重要变量。

3. **外部有效性丧失**：基于非随机样本的估计结果无法推广到总体。

4. **统计推断失效**：传统的标准误、置信区间和假设检验不再有效。

### 第2题：计量经济学中为什么需要大样本理论？

**大样本理论**，也称**渐近理论**，研究当样本容量 $n$ 趋向无穷大时统计量的性质。

**主要原因**：

1. **小样本理论假设过强**：小样本理论要求严格外生性（解释变量与所有扰动项正交）和扰动项正态分布，这在很多经济场景中难以满足。例如，含滞后被解释变量的自回归模型必然违背严格外生性。

2. **大样本理论假设更宽松**：只要求解释变量与同期扰动项不相关，不要求扰动项服从正态分布。

3. **渐近性质的实用性**：大数定律保证估计量的**一致性**，中心极限定理保证**渐近正态性**，使得在大样本下可以进行有效的统计推断。

### 第3题：什么是多重共线性？它有什么后果？有哪些解决办法？

多重共线性是指线性回归模型中解释变量之间存在高度相关关系，使模型估计失真或难以估计准确。

**后果**：

1. **参数估计方差扩大**：虽然OLS估计量仍然是无偏的，但方差增大，估计精度下降。

2. **$t$ 检验失效**：变量的显著性检验容易不显著，可能错误地剔除重要变量。

3. **系数符号与经济理论矛盾**：估计系数可能符号相反或数值不合理。

4. **模型稳定性差**：样本的微小变化可能导致估计结果剧烈变动。

**解决办法**：

1. **删除引起共线性的变量**（逐步回归法，最常用）。

2. **追加样本信息**。

3. **改变解释变量形式**（如用相对数代替绝对数、差分变换）。

4. **主成分回归**或**岭回归**（Ridge Regression）。

5. **利用非样本先验信息**。


## 三、简答题

### 第一大题：专利数量回归与数据加总问题

**题目复述**：

原始模型（企业层面）：
$$
Patent_{ij} = \beta_0 + \beta_1 RD_{ij} + \beta_2 HHI_{ij} + \beta_3 K_{ij} + \beta_4 Size_{ij} + \mu_{ij}
$$

将行业内所有企业加总取平均后进行回归：
$$
\overline{Patent_{i}} = b_0 + b_1 \overline{RD_{i}} + b_2 \overline{HHI_{i}} + b_3 \overline{K_{i}} + b_4 \overline{Size_{i}} + \mu_{i}
$$

问：平均回归有什么问题？如何变换模型以消除之？还有什么改进方法？

**解答思路**：

**（一）平均回归的问题——生态学谬误（Ecological Fallacy）**

将微观企业数据加总到行业层面进行回归，存在以下严重问题：

1. **信息损失**：丧失了企业层面的异质性信息，行业均值无法反映企业间的差异。

2. **遗漏变量偏误**：如果遗漏的企业层面变量与行业均值相关，则估计量是有偏且不一致的。

3. **聚合偏误（Aggregation Bias）**：微观层面的非线性关系在加总后可能呈现不同的形态。

4. **样本量大幅减少**：从企业数量（大样本）锐减到行业数量（小样本），估计效率降低。

**（二）变换模型以消除问题**

**方法一：组内去均值（Within Transformation）——固定效应模型**

对每个企业观测值减去其所在行业的均值：
$$
Patent_{ij} - \overline{Patent_i} = \beta_1 (RD_{ij} - \overline{RD_i}) + \beta_2 (HHI_{ij} - \overline{HHI_i}) + \beta_3 (K_{ij} - \overline{K_i}) + \beta_4 (Size_{ij} - \overline{Size_i}) + (\mu_{ij} - \overline{\mu_i})
$$

这消除了行业层面的固定效应，利用了企业层面的**组内变异**（within-group variation）来识别参数。

**方法二：一阶差分（First Difference）**

如果有面板数据，可以对每个企业进行时间上的差分，消除不随时间变化的个体固定效应。

**（三）其他改进方法**

1. **多层模型（Multilevel/Hierarchical Model）**：在行业和企业两个层面分别设定误差项，同时利用两层信息。

2. **随机系数模型**：允许不同行业有不同的斜率系数。

3. **面板数据方法**：如果数据是面板结构，使用固定效应或随机效应模型。

4. **计数数据模型**：专利数量是非负整数，应使用Poisson回归或负二项回归。

### 第二大题：生育对劳动供给的影响

> 被解释变量：劳动周数（weeks worked）  
> 核心解释变量：morekids（生育两个及以上孩子 $=1$，否则 $=0$）  
> 控制变量：black（黑人 $=1$）等

问题：

1. 解释 morekids 系数的经济含义

2. 解释 morekids 与 black 交互项系数的含义

3. 以 samesex（子女性别相同）作为工具变量的内生性检验，问 samesex 是否是内生变量

4. 接受基准模型还是工具变量模型？给出改进建议

**解答思路**：

**（一）morekids 系数的经济含义**

morekids 的系数 $\beta_1$ 表示：在控制其他变量不变的情况下，生育两个及以上孩子的女性（相对于生育一个或没有孩子的女性），其年均劳动周数的平均差异。若 $\beta_1 < 0$，说明多生育一个孩子显著降低了女性的劳动供给。

**（二）交互项（morekids $\times$ black）系数的含义**

交互项系数 $\beta_{interact}$ 表示 morekids 对劳动周数的影响在黑人群体与非黑人群体之间的差异。具体而言：

- 非黑人群体中，morekids 的边际效应为 $\beta_1$；

- 黑人群体中，morekids 的边际效应为 $\beta_1 + \beta_{interact}$；

- 若 $\beta_{interact}$ 显著不为零，说明生育对劳动供给的影响存在种族异质性。

**（三）samesex 作为工具变量的有效性**

- **相关性**：在存在性别偏好的社会中，若前两胎性别相同，家庭更可能继续生育第三胎，从而影响 morekids。

- **外生性**：子女的性别组合是随机的（近似自然实验），不应直接影响母亲的劳动供给（除通过子女数量这一渠道外）。

**（四）基准模型与工具变量模型的选择**

1. **Durbin-Wu-Hausman (DWH) 检验**：

   - 若检验的 $p$ 值 $< 0.05$，拒绝原假设，说明 morekids 确实存在内生性，基准OLS有偏，必须接受工具变量模型。

   - 若 $p$ 值 $\ge 0.05$，无法拒绝原假设，说明 morekids 在统计上可视为外生，此时应接受基准模型（OLS效率更高）。

2. **Sargan 检验或 Hansen J 统计量**：

   - 若 $p$ 值 $> 0.05$，说明工具变量整体通过外生性检验，samesex 不是内生变量（满足排他性约束）。

   - 若 $p$ 值 $< 0.05$，说明至少有一个工具变量不满足外生性，samesex 可能通过其他路径影响了劳动供给，此时模型设定有误。

3. **弱工具变量检验**：若第一阶段 $F$ 统计量 $< 10$，说明 samesex 与 morekids 的相关性极弱（弱工具变量），此时IV估计量存在严重有限样本偏误，不应采用。


### 第三大题：科研创新对公司产出的建模

> 变量关系如下：
>
> 被解释变量 $Y$：公司产出，衡量企业的最终经营绩效。  
> 核心解释变量 $X_1$：企业创新水平，采用创新词频进行量化度量。  
> 中介变量 $X_2$：公司内部管理效率。  
> 外生环境 $X_3$：我忘记了。  
> 制度环境变量 $X_4$：国家层面的创新专利激励机制（如专利补贴、知识产权保护强度），作为外生政策冲击，直接促进企业产出（$X_4 \to Y$）。  
> 外生基础设施变量 $X_6$：创新基建程度。

问题：

1. 从 $X_1$ 到 $Y$ 哪些变量需要控制？理由是什么？

2. 该模型存在哪些内生性问题？哪些可解决、哪些无法解决？如何解决？

3. 有什么方法可以加强内生性问题下的因果论述？

**解答思路**：

**（一）从 $X_1$ 到 $Y$ 需要控制的变量**

根据因果图（DAG）理论，要识别 $X_1 \to Y$ 的因果效应，需要控制**混杂变量**，即同时影响 $X_1$ 和 $Y$ 的变量：

1. **$X_3$**：$X_3 \to X_1$ 且 $X_3 \to Y$，$X_3$ 是 $X_1$ 和 $Y$ 的共同原因（混杂因子），**必须控制**。

2. **$u$**：$u \to X_1$ 且 $u \to Y$，$u$ 是**不可观测的混杂因素**，无法直接控制。

**不需要控制的变量**：

- **$X_2$**：$X_1 \to X_2 \to Y$，$X_2$ 是 $X_1$ 影响 $Y$ 的**中介渠道**。如果控制 $X_2$，会阻断 $X_1$ 通过 $X_2$ 对 $Y$ 的间接效应，估计的是**直接效应**而非总效应。

- **$X_4$**：$X_4 \to Y$ 但 $X_4$ 不影响 $X_1$，不控制也不会造成偏误。

- **$X_5$**：$X_1 \to X_5$ 且 $Y \to X_5$，$X_5$ 是**碰撞变量**，控制 $X_5$ 会引入选择性偏误，**不应控制**。

- **$X_6$**：$X_6 \to X_1$ 但不直接影响 $Y$，不是混杂因子。

**（二）内生性问题及解决方案**

**内生性问题来源**：

1. **遗漏变量偏误**：$u$（不可观测因素）同时影响 $X_1$ 和 $Y$。  
   - 可解决程度：**部分可解决**  
   - 解决方案：寻找代理变量、使用面板数据固定效应、工具变量法。

2. **测量误差**：$X_1$ 用词频衡量创新，可能存在测量误差。  
   - 可解决程度：**有限**  
   - 解决方案：使用多个测量指标、建立测量误差模型。

3. **反向因果**：$Y$ 可能反过来影响 $X_1$。  
   - 可解决程度：**部分可解决**  
   - 解决方案：使用滞后变量、工具变量法。

4. **选择偏误**：企业是否进行创新可能不是随机的。  
   - 可解决程度：**部分可解决**  
   - 解决方案：Heckman两步法、倾向得分匹配。

**无法完全解决的问题**：

- 不可观测的混杂因素：如果找不到有效的工具变量，$u$ 的影响无法完全消除。

- 测量误差的精确性质：若误差与真实值相关，难以完全校正。

**（三）加强因果论述的方法**

1. **工具变量法**：寻找外生的工具变量（如政策冲击、地理特征等），通过2SLS估计因果效应。

2. **面板数据方法**：
   - 固定效应模型：控制不随时间变化的不可观测异质性。
   - 差分GMM：处理动态面板中的内生性。

3. **准实验方法**：
   - 双重差分法（DID）：利用政策冲击的外生变动。
   - 断点回归（RDD）：利用制度阈值附近的近似随机分配。

4. **稳健性检验**：
   - 替换核心变量度量方式。
   - 增加控制变量集合。
   - 安慰剂检验（placebo test）。
   - 排除其他竞争性解释。
