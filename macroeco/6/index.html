    在中期，经济倾向于向与自然失业率对应的产出水平回归

    劳动力市场是衡量经济健康状况的重要指标，其状况是通货膨胀率的主要驱动因素之一。

    回顾一下劳动力的几个概念定义，失业率，就业率，劳动参与率等等。

    劳动力市场概况¶

    在分析劳动力市场时，我们关注的是人口、劳动力、就业与失业之间的关系。

    • 非劳动力 既没有工作也不找工作的人。
    • 劳动力： 就业者 (\(N\)) + 失业者 (\(U\))。
    • 失业率： 失业人数占劳动力的百分比，\(u = U/L\)。
    • 参与率： 劳动力占劳动年龄人口的比例。

    对于失业率的理解，有一个经典例子，来自布兰查德德书：

    假设一个机场挤满了乘客，一种原因可能是该机场非常繁忙，有许多飞机起飞和降落，而众多乘客也迅速出入于机场之间；另一种原因可能是坏天气延误了航班导致乘客滞留，乘客在等待天气转好。 在两种情况下乘客人数可能是相同的，但他们的情形却是完全不同的。在第二种情形的乘客多半会更沮丧。

    值得注意的是，流入非劳动力的人口非常巨大，同时非劳动力流入劳动力市场的流量亦不可忽视。这说明非劳动力市场中的个体并非不参与生产，布兰查德将其称为“丧失信心的“工人，如果有明显的劳动机会，他们会参与生产。因此就业率有时比失业率更为客观。

    然而，我们依然按照传统将失业率作为测量劳动力市场的指标。

    工资决定：工人视角¶

    在讨论了失业之后，我们来研究工资决定以及工资和失业的关系。

    工资并不是简单由供需曲线交点决定的，而是通过集体谈判或个体议价达成的2。但是，虽然各国工资制度差异显著，也有一些共同影响因素。工人必须拿到保留工资，类似于保留价格，工人就业必须要有劳动的报酬。同时，失业率越高的情况下，工资一般越低。

    工资决定方程¶

    \[W = P^e F(u, z)\]
    • \(W\) (名义工资)： 雇员拿到的货币工资。
    • \(P^e\) (预期价格水平)： 工人关心的是实际工资 (\(W/P\))。由于合同通常是预先签订的，所以取决于对未来价格的预期。5
    • \(u\) (失业率)： 失业率越高，工人的议价能力（Bargaining Power3）越低，工资越低。
    • \(z\) (结构性变量)： 包含所有影响工资的其他因素（如失业保险、最低工资法、工会保护）。\(z\) 增加，工资上升。

    工人的议价能力取决于公司找到劳动力的成本与工人自己求职的成本，所以，失业率上升的时候公司的劳动力市场充裕，工人议价能力下降。

    价格决定：公司视角¶

    公司并非不愿意支付高于保留工资的工资，高工资可以吸引员工工作4。但是设定工资必须与公司商品的价格挂钩。价格决定于公司的成本，又取决于生产函数：

    \(\(Y=AN\)\) 其中 \(Y\) 是产出，\(A\) 是劳动生产率，\(N\) 是雇佣就业，我们假定劳动是唯一生产要素，而资本等要素不在本模型之列。

    假设生产函数简化为 \(Y = AN\)（简化为 1，长期的时候会继续讨论 \(A\) 的变动 ），则边际成本就等于工资 \(W\)（非常重要！）。

    由于企业通常具有一定的市场势力1，会在成本基础上加价：

    \[P = (1 + m)W\]
    • \(m\) (Mark-up)： 价格加成。如果市场竞争激烈，\(m\) 就会降低；如果是垄断市场，\(m\) 就会升高，这和微观经济学中的理论是一致的。
    • 由此推导出的实际工资： \(\frac{W}{P} = \frac{1}{1+m}\)

    自然失业率：均衡视角¶

    自然失业率一点也不“自然”6。它不是由自然法则决定的，而是由经济结构决定的。它本质上是指当人们对价格的预期完全正确（\(P^e = P\)）时的均衡失业率水平。

    在劳动力市场中，工资合同通常是基于对未来的预期价格 (\(P^e\)) 签订的,工人可能会猜错价格（比如通胀比预想的高），此时失业率会偏离自然率。中长期内，人们会调整预期，错误会消失。因此，自然失业率被视为经济在中期**倾向于回归的平均水平。

    当工资设定 (WS) 与 价格设定 (PS) 相等时，市场达到均衡。

    • WS 关系： \(\frac{W}{P} = F(u, z)\)
    • PS 关系： \(\frac{W}{P} = \frac{1}{1+m}\)

    自然失业率方程：

    \[F(u_n, z) = \frac{1}{1+m}\]

    这个方程决定了自然失业率与 \(z\) ,\(m\) 的关系。其中均衡的 \(u_{m}\) 失业率称为自然失业率。改变 \(z,m\) 就会相应地影响 \(u_{m}\) 的动态平衡。例如，增加失业救济金发放：

    \(z,m\) 都是结构性经济变量，所以 \(u_{n}\) 更应该称为结构性失业率，不过至今该名称都没有被普遍采用。

    失业、就业与产出¶

    自然就业水平反映了自然失业均衡时的就业水平：\(\(N=L(1-u_{m})\)\)考虑到我们假定的生产函数 \(\(Y=AN\)\)有 \(\(Y_{n}=N_{n}=L(1-u_{n})\)\)

    中期¶

    需要注意，我们的理论已经进入了经济发展的中期时间，但是为什么我们不像前几章短期研究中一样，考虑货币政策，财政政策？为什么消费者信心之类的因素不影响自然产出？

    因为我们的假设是在中期中实现的，没有理由认为，短期内价格水平能够稳定，也没有理由认为短期内就能做好工资的预测。短期内决定产出的变动的因素依然是货币政策，财政政策等等。

    中期经济研究对短期的启示是，短期内不太可能出现严重的系统性错误。例如，产出率严重偏离自然产出率，失业率严重偏离了自然失业率，这通常意味着经济危机，经济爆发，或者统计出错了。
